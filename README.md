📊 Data-Driven Customer Retention Strategy..!

----------------------------------------------------------------------------------------------
📌 Project Overview:

- Customer churn is a critical business challenge where companies lose existing customers.
This project presents an end-to-end data science solution using Machine Learning, Flask, and Tableau to predict customer churn and provide actionable, data-driven business insights.

----------------------------------------------------------------------------------------------
🎯 Problem Statement:

-In the telecom industry, customer churn directly impacts revenue and growth.
-The objective of this project is to:

1] Predict whether a customer is likely to churn.

2] Identify high-risk customers.

3] Support businesses in building effective customer retention strategies.

----------------------------------------------------------------------------------------------
🧠 Solution Approach:

1] Data Analysis & Preprocessing:

	-Used the Telco Customer Churn dataset

	-Handled missing values and data cleaning

	-Encoded categorical variables and scaled numerical features

2] Machine Learning Model:

	-Implemented Logistic Regression for churn prediction

	-Applied feature scaling using StandardScaler

	-Saved trained model and scaler using pickle

3] Web Application (Flask):

	-Built a Flask-based web app for churn prediction

	-Users can input customer details and get instant predictions

	-Simple and clean user interface

4] Data Visualization (Tableau):

	-Designed an interactive Tableau dashboard

	-Displayed KPIs and churn analysis insights

----------------------------------------------------------------------------------------------
🛠️ Tech Stack:

	- Programming Language: Python

	- Libraries: NumPy, Pandas, Scikit-learn

	- Web Framework: Flask

	- Deployment: Render (Free Tier)

	- Visualization: Tableau

	- Version Control: Git & GitHub

----------------------------------------------------------------------------------------------
📊 Tableau Dashboard Insights:

The Tableau dashboard highlights:

	- Overall Churn Rate

	- Churn by Contract Type

	- Churn by Payment Method

	- Churn by Internet Service

	- Tenure vs Churn Analysis

📌 Key Insight:

	- Customers with Month-to-Month contracts and Electronic Check payment methods show a higher probability of churn.
